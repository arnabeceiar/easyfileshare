# Easy File Share (EasyFileShare) V 1.0 - Architectural Considerations #

## Purpose
- The purpose of developing the utility is to create a FTP server style file sharing over internet **without** any public **in-bound TCP ports**.  

- The server, hosting shareable files is not effectively an in-bound path for any traffic. It's a **reverse tunnel rather**. 

- The utility offers a shareable service and will remain alive even with power-cycle unless the user deliberately stops the sharing service.
  

## Basic considerations

1. **Artefacts :** Third party free / open-source battle-tested tools wherever possible.
   
2. **Transfer Engine :** **Magic wormhole** as the transfer engine. No need to devise custom own transfer engine on **www.techsapio.com** as  of now. The traffic doesn't contribute to any SEO. So better with free relay + rendezvous server supported by Magic Wormhole.
   
3. The DB hosted at **www.techsapio.com** will offer a table for storing user details.
   
4. **User account creation :** The utility will require the user to login / create a user account feature.
   
5. **Password / Account recovery :** The utility will have a feature for password / account recovery. Presently mobile number based OTP won't be supported. E-mail basec recovery will be provided.
   
6. **User account information :** User account information will be stored in a database in **www.techsapio.com**. The user credentials with priviledge will be stored in that DB row.

7. **Server unique path :** The server identification in website Db will be marked with username (every username would be unique) followed by a timestamp number (posix format).

8. **Server information :** Once the server service created, a folder with unique path name will be created in shared hosting. That folder will contain .json and some other info files - e.g., directory tree etc.
